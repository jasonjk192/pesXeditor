About
-----

This project is based on [4ccEditor](https://github.com/the4chancup/4ccEditor) and uses a fork of [pesXdecrypter](https://github.com/the4chancup/pesXdecrypter) for the encrypt/decrypt library.

This project is only a wrapper and uses code from the original project to expose load/save functionalities without the UI elements so it can be built into a .dll file.

This project is developed for personal and educational use.



Usage
-----

This project uses solutions to setup and build it.
- Go to the Project's properties (right-click the project in solution explorer or select Project > Properties from the menu bar).
- In Configuration Properties > General, change the 'Configuration Type' to your needs.
- To Build, simply run the 'Build Solution' or 'Build pesXeditor' under Build menu.
